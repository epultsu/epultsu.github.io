# e-pult.su

Статический сайт ООО «Е-Пульт», размещается на GitHub Pages (домен в файле `CNAME`).

- Страницы — HTML-файлы в корне; стили — `assets/css/main.css`, скрипт меню и формы — `assets/js/main.js`.
- Картинки кладутся в `img/` под именами из файла с промптами. Пока файла нет, на его месте видна рамка с именем.
- Старые адреса (`smart-*.html`, `security-page.html`) перенаправляют на новые страницы.
- Форма заявки по умолчанию открывает письмо на info@e-pult.su в почтовой программе посетителя. Чтобы заявки приходили напрямую, подключите обработчик форм (например, Formspree) и укажите его адрес в атрибуте `data-endpoint` у тега `<form data-lead>`.
- Для тёмной темы у каждой картинки может быть вторая версия с суффиксом `-dark` (`hero-home.webp` → `hero-home-dark.webp`). В тёмной теме сайт берёт её, а если её нет — обычную.
